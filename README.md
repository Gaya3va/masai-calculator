# masai-calculator



This project is a simple static calculator layout created using **HTML** and **internal CSS**.  
It matches the design provided in the assignment, including the heading style, button layout, shadows, spacing, and overall structure.

## Features
- Clean UI using pure HTML + internal CSS
- 4×4 button grid (numbers + operators)
- Display area at the top
- Styled operator buttons (black)
- Styled clear button (red)
- Fully responsive and centered layout

## Technologies Used
- HTML  
- CSS (internal styling only)

## How to Use
1. Open `masai-calculator.html` in any browser.
2. View the static calculator layout as required by the assignment.

## Notes
- This assignment focuses on **layout only**, not functional JavaScript.
- Styling follows the exact screenshot reference.
